블로그 하나를 만드는 데 고를 수 있는 선택지가 너무 많습니다. 노션 API, 헤드리스 CMS, 워드프레스, 정적 사이트 생성기.

## 기준은 "자동화가 무엇을 해야 하는가" {#criterion}

이 프로젝트의 목적은 자동으로 글을 꽂아 넣는 것입니다. 그러니 질문은 "어디가 예쁜가"가 아니라 "스크립트가 글 하나를 넣으려면 무엇을 해야 하는가"입니다.

| 방식 | 스크립트가 하는 일 |
| --- | --- |
| 정적 + 마크다운 | 파일 쓰고 커밋 |
| 헤드리스 CMS | API 키 관리, 스키마 맞춤, 요청 |
| 노션 | API 키 관리, 블록 구조로 변환 |

첫 줄이 압도적으로 단순합니다. 게다가 GitHub 업로드 자동화와 같은 저장소를 쓸 수도 있습니다.

## 옮길 때를 미리 정해 둔다 {#when-to-move}

"나중에 필요하면 옮기지"는 대개 안 옮깁니다. 그래서 조건을 적어 두었습니다.

- 게시물 종류가 셋을 넘어갈 때
- 나 말고 다른 사람이 쓰기 시작할 때
- 빌드가 1분을 넘어갈 때

셋 중 하나라도 오면 헤드리스 CMS를 봅니다. 그전까지는 파일이 데이터베이스입니다.
