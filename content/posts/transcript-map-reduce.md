두 시간짜리 강연 자막은 대략 2만 자입니다. 컨텍스트에 넣지 못할 양은 아니지만, 통째로 던져서 나온 요약은 대체로 밋밋합니다. 앞부분 이야기만 자세하고 뒤로 갈수록 뭉뚱그려집니다.

## 챕터가 있으면 챕터를 쓴다 {#use-chapters}

유튜브 설명란의 타임스탬프 목록은 사람이 직접 나눈 경계입니다. 이보다 나은 분할 기준을 자동으로 만들기는 어렵습니다. 챕터가 있으면 그대로 쓰고, 없을 때만 길이 기준으로 자릅니다.

- 챕터 있음 → 챕터별로 자른다
- 챕터 없음 → 4,000자 내외로 자르되 문장 경계에서 끊는다
- 어느 쪽이든 앞뒤 200자쯤 겹치게 둔다 (경계에서 맥락이 끊기지 않도록)

## 두 단계 {#two-passes}

1단계는 조각별 요약입니다. 각 조각에서 "무엇을 말했는지"와 "인용할 만한 문장"을 뽑습니다. 2단계는 그 요약들을 모아 전체 구조를 만듭니다.

> [!TIP]
> 1단계 프롬프트에 "이 조각만 보고 전체를 추측하지 말 것"을 명시하세요. 없으면 각 조각이 저마다 결론을 지어내고, 2단계에서 서로 어긋나는 결론 여러 개를 합치게 됩니다.

## 실패를 상태로 남긴다 {#failures}

요약이 실패하는 이유는 네 가지쯤 됩니다 — 자막 없음, API 오류, 토큰 초과, 쿼터 소진. 이걸 전부 "실패"로 뭉뚱그리면 재시도할 때 무엇을 고쳐야 할지 알 수 없습니다. 사유별로 다른 문구를 남기고, 자막 없음처럼 재시도해도 소용없는 경우는 재시도 버튼 자체를 주지 않습니다.
