# 0001. 결정을 ADR로 기록한다

- 상태: 채택
- 날짜: 2026-10-12

## 맥락

README에 "왜 이렇게 했는가"가 섞여 있어 길어지고, 결정이 바뀌어도 이전 판단이 남지 않습니다.
이 저장소는 포트폴리오이기도 해서, 결과물만큼 판단 과정이 읽혀야 합니다.

## 결정

되돌리기 어렵거나 대안을 버린 결정은 `docs/adr/`에 한 장씩 남깁니다. 결정이 바뀌면 원문을
고치지 않고 새 ADR이 이전 것을 "대체"합니다.

## 결과

- 좋은 점: 결정의 시점과 맥락이 커밋 이력과 함께 남습니다. 케이스 스터디의 원재료가 됩니다.
- 감수하는 점: 작은 결정까지 쓰면 소음이 됩니다 — PR 본문으로 충분한 것은 PR에 둡니다.
