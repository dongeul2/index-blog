# 0004. 블로그를 포트폴리오 구조로 재편한다

- 상태: 제안
- 날짜: 2026-10-12

## 맥락

지금은 글이 분류·태그로만 나뉘어 있고, 실제 역량(RLS 설계, Realtime, AI 스트리밍, 쿼터 설계)은
대부분 `/admin` 안에 있어 방문자에게 보이지 않습니다.

## 결정

사이트를 이력서의 근거로 재편합니다 — 소개(`/about`), 회사 프로젝트(`/work`), 개인 프로젝트
(`/projects`), 일하는 방식(`/process`), 라이브 데모(`/lab`), 품질·운영 지표(`/quality`, `/status`,
`/changelog`), 제작기(`/how-built`). 글(`/notes`)은 프로젝트에 딸린 보조 영역이 됩니다.

- 태그는 "역량" 축으로 승격해 프로젝트·데모·글을 한데 묶습니다.
- 프로젝트 상세는 기획 · 설계 · 구현 · QA · 운영 · 회고 단계 탭을 가진 케이스 스터디입니다.
- 회사 프로젝트는 항목별 `confidential` 표시로 공개 범위를 정합니다.
- 실시간 기능은 Supabase Realtime으로 먼저, 직접 만든 WebSocket 서버는 이후 별도 호스팅으로.
- 디자인은 기존 "제도 도면" 정체성을 유지하고 모션(선 그리기, 스크롤 연출, View Transitions)을
  더합니다. 읽기 영역은 조용히 둡니다.

세부 순서는 [ROADMAP.md](../ROADMAP.md).
